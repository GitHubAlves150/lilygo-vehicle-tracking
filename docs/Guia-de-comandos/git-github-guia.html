Instalação e Setup

PASSO 1
Instalar Git (Ubuntu)
sudo apt update && sudo apt install git
Configurar nome de usuário
git config --global user.name "Seu Nome"
Configurar email
git config --global user.email "seu-email@exemplo.com"
Editor padrão (nano)
git config --global core.editor "nano"
Ver configurações
git config --list
Pronto! Git instalado e configurado globalmente.

Comandos Básicos Locais

PASSO 2
Iniciar repositório
git init
Cria um novo repositório Git na pasta atual.
Adicionar arquivo(s)
git add arquivo.txt
git add .
git add --all
Prepara arquivos para commit (staging area).
Fazer commit
git commit -m "mensagem descritiva"
git commit -am "pula o git add"
Ver histórico
git log --oneline --graph --all
Histórico de commits formatado.
Status atual
git status
Mostra arquivos modificados/untracked.
Ver diferenças
git diff
git diff --staged

Branches (Ramos)

PASSO 3
Listar branches
git branch
git branch -a
Com -a mostra branches locais e remotos.
Criar branch
git branch nome-da-branch
Mudar de branch
git checkout nome-da-branch
git switch nome-da-branch
Criar e mudar
git checkout -b nova-branch
git switch -c nova-branch
Merge
git merge nome-da-branch
Faz merge da branch nomeada na branch atual.
Deletar branch
git branch -d nome-da-branch

GitHub (Remotos)

PASSO 4
Clonar repositório (HTTPS)
git clone https://github.com/usuario/repositorio.git
Clonar com SSH (recomendado)
git clone git@github.com:usuario/repositorio.git
SSH evita digitar senha/token a cada push.
Verificar remote
git remote -v
Adicionar remote
git remote add origin git@github.com:usuario/repo.git
Enviar (push)
git push -u origin main
git push origin main
-u configura upstream (próximo push sem argumentos).
Baixar (pull)
git pull origin main
Busca e mescla alterações do remoto.
Gerar chave SSH: ssh-keygen -t ed25519 -C "email@exemplo.com". Depois adicione ao GitHub (Settings → SSH Keys).

Desfazer e Recuperar

CORREÇÕES
Desfazer add (unstage)
git restore --staged arquivo.txt
git reset HEAD arquivo.txt
Desfazer modificações
git restore arquivo.txt
git checkout -- arquivo.txt
Restaura arquivo para o último commit (cuidado: perde alterações!).
Desfazer último commit
git reset --soft HEAD~1 # mantém alterações
git reset --hard HEAD~1 # perde alterações
Abortar merge com conflito
git merge --abort
Baixar sem merge (fetch)
git fetch origin
Cuidado: git reset --hard e git restore perdem alterações não commitadas.

.gitignore e Boas Práticas

FLUXO IDEAL
Exemplo de .gitignore
# Arquivos compilados
*.o
*.elf
*.bin

# IDE
.vscode/
__pycache__/

# Credenciais
.env
secrets.txt
Crie o arquivo .gitignore na raiz do projeto.
Criar tag
git tag -a v1.0.0 -m "Primeira versão estável"
git push origin v1.0.0
Rebase (atualizar branch)
git fetch origin
git rebase origin/main
Fluxo recomendado para seu projeto:
git add . → git commit -m "descrição" → git push origin main
